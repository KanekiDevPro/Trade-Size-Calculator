## ✨ امکانات

### هسته محاسبات
- 📊 محاسبه سایز پوزیشن با فرمول استاندارد ریسک
- 💰 ریسک دلاری برنامه‌ریزی‌شده در هر معامله
- 🧮 چندین سطح ریسک همزمان (مثل `0.25, 0.5, 1, 2`)
- ⚡️ اهرم تا 125× + محاسبه مارجین لازم
- 🔺🔺 پشتیبانی از **Long و Short** (مدل هزینه‌ها برای هر دو درست است)

### ایمنی و هشدارها
- ⚠️ هشدار وقتی سایز پوزیشن یا مارجین از سرمایه بیشتر شود
- 💀 **فاصله تقریبی تا لیکویید** (`100 ÷ اهرم − MMR`) + مقایسه با حد ضرر:
  🚨 لیکویید قبل از SL / ⚠️ خیلی نزدیک / ✅ SL اول فعال می‌شود
- 🧯 ورودی اختیاری **MMR** (نرخ مارجین نگهداری صرافی)

### عدد واقعاً قابل اجرا در صرافی
- 🪙 **گرد کردن حجم به stepSize صرافی** با `ROUND_DOWN` (ریسک واقعی هرگز از برنامه بیشتر نمی‌شود)
- 📋 **دریافت خودکار لیست نمادها، قیمت و stepSize/minQty** از صرافی (بدون API key)
- 🛡 چک **minQty** — اگر حجم گردشده از حداقل مجاز کمتر باشد، سفارش رد می‌شود و شما زودتر باخبر می‌شوید

### شفافیت هزینه‌ها
- 📝 کارمزد taker دو طرف + اسلیپیج نامساعد در ورود و خروج (فرمول دقیق per-unit)
- 📉 سود **خالص** و **R:R خالص** جدا از مقادیر نظری + هشدار وقتی سود خالص منفی می‌شود

### تجربه کاربری
- 🇮🇷 رابط کاملاً فارسی و راست‌چین با فونت Vazirmatn
- 🔢 تایپ اعداد **فارسی و عربی**: ممیز `٫` و `/`، کامای فارسی `،` (مثال: `۰/۲۵، ۰/۵، ۲`)
- 💾 نتیجه با تغییر ورودی‌ها پاک نمی‌شود (session_state)
- 🎯 حد سود اختیاری (toggle)

## 🧠 منطق محاسبات

```
Dollar Risk    = Capital × Risk%
Position Size  = Dollar Risk ÷ SL%
Margin         = Position Size ÷ Leverage
Liq Distance   ≈ 100 ÷ Leverage − MMR
Qty            = floor(Position Size ÷ Entry Price تا مضرب stepSize)
Real Loss      = Qty × (اختلاف قیمت اجرای ورود/خروج + کارمزد دو طرف)
Net Reward     = Qty × (اختلاف قیمت TP − کارمزد دو طرف)
R:R خالص       = Net Reward ÷ Real Loss
```

- همه محاسبات با `Decimal` انجام می‌شوند (بدون خطای اعشار float)
- مدل بازار: Spot و فیوچرز **خطی (Linear)** — قراردادهای Inverse/ضریب‌دار جدا هستند
- هزینه‌های لحاظ نشده: maker fee، فاندینگ، هزینه قرض‌گیری اسپات، هزینه لیکویید

## 🚀 دیپلوی روی Streamlit Cloud

1. پروژه را در گیت‌هاب push کنید با این ساختار:

```
trade-size-calculator/
├── app.py
├── requirements.txt
└── README.md
```

2. محتوای `requirements.txt`:

```
streamlit
pandas
ccxt
```

3. در [share.streamlit.io](https://share.streamlit.io):
   - **New app** → ریپو و برنچ را انتخاب کنید
   - Main file: `app.py` → **Deploy**

4. برای به‌روزرسانی: هر push به همان برنچ به‌صورت خودکار redeploy می‌شود.

> ⚠️ روی سرورهای ابری آمریکایی، API بایننس معمولاً geo-block است.
> پیش‌فرض صرافی برنامه **Bybit** است؛ اگر خطای دسترسی گرفتید، صرافی دیگری انتخاب کنید.
